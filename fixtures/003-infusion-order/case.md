## 一、★ 这次就诊的完整时间线

| 时刻 | 事件 | `event_time_source` |
|---|---|---|
| 16:54 | 超声报告(用例 002) | `report_time` |
| **17:07** | **采血**(血气 + 血常规,用例 001) | `collected_at` |
| 17:17 / 17:22 | 血气 / 血常规审核 | — |
| **18:02** | **输液单打印 ≈ 开始给药** | `print_time` |

**实际顺序:先超声 → 再抽血 → 再输液。**

三种文档的"事件时刻"来自**不同字段、语义不同**,不能直接比大小 —— 这是 `event_time` + `event_time_source` 存在的理由([ADR-032](../../docs/adr.md))。

## 二、★★ 输液直接改变后续检验值

血气(17:07):HCO₃⁻ **19.5 ↓**、细胞外液碱剩余 **−5**、pCO₂ 偏低。
输液(18:02 起):葡萄糖 + 氯化钠 + **氯化钾** + 维生素B6 + 西咪替丁。

**补钾补钠补糖之后再抽血,电解质与血气结果与输液前不可同日而语。**

这是「分析前变异 → 药物影响」的最强形态 —— 不是「最近在吃什么药」,而是「**两小时前静脉输了什么**」。

### 期望行为

```
✅ 趋势图上给药事件与检验时间点对齐显示(时间轴叠加,不是两张图)
✅ 中性标注:「该次采样时间早于本次输液」
❌ 「因此钾偏低不可信」—— 不解读影响方向
```

→ `medication.administered_at` 必须精确到分,不能只有日期。

## 三、输液单的结构:分组

```
第1组(250 mL,静滴,ONCE 1天)
  5% 葡萄糖注射液(科伦250ml,23年集采)     250 毫升
  10% 氯化钠注射液(兴华,23年集采)          10 毫升
  15% 氯化钾注射液(25年国采)                 3 毫升
  维生素B6注射液(广州,23年集采)            50 毫克

第2组(100 mL,静脉续滴,ONCE 1天)
  0.9% 氯化钠注射液(川100ml,23年集采)     100 毫升
  西咪替丁注射液(福州海王)                 0.15 克
```

**同组药物混在同一袋液体里输**,共享给药时刻与速度。扁平的 `medication` 表装不下 → `administration_group` + `sequence`。

### 处方 ≠ 输液单

| | `prescribed` | `administered` |
|---|---|---|
| 语义 | 计划给药 | **已执行给药** |
| FHIR | `MedicationRequest` | `MedicationAdministration` |

## 四、药物剂量是另一套单位体系

同一张单上并存:

| 类别 | 出现形式 |
|---|---|
| 体积 | 250 / 10 / 3 / 100 **毫升** |
| 质量 | 50 **毫克**、0.15 **克** ← **混用** |
| 浓度 | 5% / 10% / 15% / 0.9% |

`0.15 克 = 150 毫克`。浓度 × 体积可算实际溶质量:

- 10% 氯化钠 10 mL = **1 g NaCl**
- 15% 氯化钾 3 mL = **0.45 g KCl**

`packages/medical/src/units/` 只处理检验单位 → **需要独立的 `units/dose` 模块**,两套体系不可混用。

化验单上没有电话,**输液单上印着家长手机号**。

| 字段 | 处理 |
