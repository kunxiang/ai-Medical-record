# 用例 002 · 影像纵向追踪(超声,相隔两年)

> 真实报告,已脱敏。原始影像不入库。

**这是第一个纵向用例** —— 同一患者、同一问题、相隔两年的两份超声报告。它检验的不是单次提取,而是**跨时间点的可比性**。

## 背景

| | 报告 A | 报告 B |
|---|---|---|
| 日期 | 2024-08-25 15:43 | 2026-08-17 16:54 |
| 年龄 | 1 岁 | 3 岁 |
| 科室 | **外科门诊** | **内科急诊** |
| 检查目的 | **专查**阴囊 + 腹股沟 | 查腹泻的腹部超声,**阴囊顺带** |
| 超声号 | `20240825206` | `US2608170187` |
| 患者标识 | 门诊号 `240400009300` | 登记号 `0003268375` |

> 登记号 `0003268375` 与[用例 001](../001-pediatric-emergency/)、[用例 003](../003-infusion-order/) 相同 —— 四份单据靠它归到同一人。

## 一、⚠️ 头号陷阱:结论「消失」不等于问题消失

| | 报告 A(2024) | 报告 B(2026) |
|---|---|---|
| 结论 1 | 右侧精索、睾丸鞘膜积液 | 右侧睾丸鞘膜积液 |
| 结论 2 | **左侧鞘状突未闭** | — |
| 结论 3 | — | 胃、肠管声像未见明显异常 |
| 结论 4 | — | 腹腔未见明显增大阑尾及异常淋巴结声像 |
| 结论 5 | — | 腹腔未见明显包块及游离积液声像 |

第二条结论在新报告里没有出现。**但这不是"好转"**:

- 报告 A 是外科**专项检查**,还特意记录了「哭闹时」的诱发表现
- 报告 B 是急诊**顺带扫查**,没做诱发动作

**覆盖范围与手法根本不同,结论不可直接对比。**

### 期望行为

```
✅ 并列呈现,显式标注「本次检查项目不包含腹股沟诱发试验」
❌ 渲染成「左侧鞘状突未闭已消失/已好转」
❌ 对差异做任何解读
```

→ 依赖 `document.exam_items`。**不记录覆盖范围,就无法区分「查了没发现」与「根本没查」。**

## 二、可纵向追踪的测量值

| | 报告 A(2024) | 报告 B(2026) |
|---|---|---|
| 左睾丸 | 1.3 × 0.7 × 0.6 cm | 1.4 × 0.6 × 0.9 cm(报告估算体积 **0.39 cm³**) |
| 右睾丸 | 1.3 × 0.7 × 0.7 cm | 1.3 × 0.7 × 0.8 cm(报告估算体积 **0.37 cm³**) |
| 积液最大横径 | 未给数值 | 0.9 cm |

### 椭球体积校验(`ellipsoid_volume`)

`V = 0.5236 × L × W × H`

| | 计算 | 报告 | 偏差 |
|---|---|---|---|
| 左(2026) | 1.4×0.6×0.9×0.5236 = **0.3958** | 0.39 | 1.5% |
| 右(2026) | 1.3×0.7×0.8×0.5236 = **0.3812** | 0.37 | 3.0% |

**公式成立 → 给报告 A 补算,使两个时间点可比:**

| | 2024(派生) | 2026(报告) |
|---|---|---|
| 左 | 0.286 cm³ | 0.39 cm³ |
| 右 | 0.334 cm³ | 0.37 cm³ |

派生值置 `is_derived = true`、`derived_formula = ellipsoid-0.5236`。

> **系统只做到"落到同一根轴上"为止。** 数值变化意味着什么由医生判断 —— 影像测量值没有参考区间,报告本身也不给。

## 三、暴露的设计缺口

| # | 发现 | 处理 |
|---|---|---|
| 1 | **影像报告的数据结构完全不同于化验单** —— 叙述段 + 结论列表 + 建议,原模型一个字段都没有 | 新增 `report_narrative` 表([ADR-027](../../docs/adr.md)) |
| 2 | **测量值是三维的**,标量字段装不下 | 新增 `observation.value_dimensions` |
| 3 | **解剖部位是新维度** —— 左右睾丸是两条独立时间序列 | 新增 `observation.body_site`([ADR-029](../../docs/adr.md)) |
| 4 | `【...@@...@@...】` 的 `@@` 是 HIS 字段分隔符 | 拆成数组,不当文本 |
| 5 | 同一人两种患者标识:门诊号(单次) vs 登记号(长期) | `identifier_type` 区分;归人优先用长期标识 |
| 6 | 超声号格式变了(`20240825206` → `US2608170187`,系统升级) | `report_no` 只做唯一性,**不解析格式** |
| 7 | 年龄只到"岁"(比化验单的"3岁0月"粗) | 年龄不可作归人强信号;必须存 `birth_date` |
| 8 | **影像报告没有参考区间** | `ref_low/high` 全 null;绝不做正常/异常暗示 |
| 9 | 结论措辞有规范含义(「未见明显异常」≠「正常」) | 逐条原文保留,不改写不归一 |
| 10 | 报告内嵌 2 张超声截图 | 识别为图像区域,不解读 |

## 四、「顺带检查」的第一个真实证据 ★

报告 B 的检查项目栏:

```
胃肠道及腹膜腔扫查超声【胃及十二指肠@@阑尾及系膜淋巴结@@下消化道】阴囊、双侧睾丸、附睾超声
```

主诉是腹泻/呕吐,**阴囊超声是顺带做的** —— 于是产生了鞘膜积液的随访数据。

这正是项目最初要解决的问题:「每次检查不一定针对该问题,但顺带查到的值应能纳入长期记录」。

→ 监控组必须支持 `item_type ∈ (lab, imaging_measure, conclusion)`,否则这条路径断掉。
