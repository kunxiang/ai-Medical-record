# 09 · 路线图

## 0. 排序原则

**归档能力抢时间,医学能力慢慢长。**

- 热敏纸在褪色,旧单据在丢失,情境记忆在过期 —— 这些**有时效性**,先做
- 医学解读能力可以在存量数据上后补 —— 因为原件在手,派生层随时可重生

因此:先把管道打通,再谈智能。

## 0b. 2026-08-28 Core 重基线

早期 M0–M8 编号保留为历史路线，但不再把 M2 AI 资格当作后续产品能力的前置依赖。现行发布基线以 [`specs/p0-p4-core/`](../specs/p0-p4-core/) 为准：

| 轨道 | 当前状态 | 仍待完成 |
|---|---|---|
| Core-0/P0–P4 | 功能实现与无 AI 自动验收已完成 | owner 桌面/手机、耗时 gate，以及 3–5 名医生的导出可读性 gate |
| AI processing plugin（原 M2） | Stage 1 与部分 rollout 存在 | 独立 A/B 编排、真实 wire；20 份脱敏真实单据已经 owner 允许延后 |

Core 默认 `PROCESSING_MODE=off`，模型/provider/prompt/cassette/真实单据质量不是 P0–P4 发布 gate。未确认 AI 建议不进入搜索事实、趋势或导出。

- [x] `_meta/` 自述层落桶:README(布局/回放规则/journal 事件注册表)+ schema 快照 + 注册表快照(ADR-045)
- [x] **最小上传链**(presign → 直传 → 登记;capture.json 随登记即写)与 **journal 双写机制**(M0 事件:person_update)—— spec 审核 #001 裁决:M0 验收句要求上传,D1 原则要求 journal 随建档同批(见 specs/m0/)
- [x] `packages/storage`:key 生成/解析 + sidecar 序列化 + 往返测试
- [x] 账号认证 + `person_access` 授权中间件(**从第一天起所有查询都过这一层**)
- [x] 建档 API
- [x] PWA 家庭成员建档入口（补录于 2026-08-26；创建后写入精简缓存并自动切换）

**验收:** 用 curl 建一个 person,上传一张图,能在 S3 里用 `rclone ls` 看到人类可读的路径与 sidecar。

## M1 · 归档管道(P0 核心)

**目标:拍照 → 入库,弱网可用。这一步做完,系统就已经有价值了。**

- [x] PWA 侧接入 M0 既有上传链(presign 直传 + `POST /documents` 幂等键)
- [x] PWA:拍照(含连拍模式)、PDF/截图/相册导入
- [x] **IndexedDB 离线队列 + 前台驱动重试**(ADR-046:iOS 无 Background Sync;SW 只做外壳预缓存)
- [x] 采集端 EXIF 读取(`DateTimeOriginal` → `captured_at`;`Orientation` 落 page sidecar)—— 存量旧单据的归档日期正确性依赖它
- [x] CORS(API 侧 + 桶侧,M0 挂账)、**D11 权限审计落点**、**D12 token 吊销**(到期债)
- [x] 上传队列状态 UI(「3 张待上传」)
- [x] 家庭成员选择与新增（复用 M0 建档 API）
- [x] journal 双写扩展到 M1 新增的人工输入(机制已在 M0 落地;此后每个产生人工输入的功能都必须接入,ADR-045 / D1)
- [x] 缩略图 / 预览图生成
- [x] 文档浏览:按人 → 时间轴 → 文档(只读;**软删除移至 M2**,与归人纠正、文档拆分同批)

**验收:** 飞行模式下拍 5 张 → 恢复网络 → 全部上传成功,一张不丢。

> ⏰ **此时开始抢救存量:** 系统一可用就集中扫描家里的旧单据,越老的越优先。热敏纸在褪色。

## M8 · 加固

**目标:让档案活得比应用久。**

- [ ] 第二处备份(rclone 定时同步)

- [ ] `tools/rebuild-index`:从 S3 manifests 完全重建数据库
- [ ] **恢复演练**(半年一次)
- [ ] 批量导入工具(存量单据)
- [ ] 数据导出(全量 zip + JSON)

**验收:** 删掉整个数据库,能从 S3 完全重建,**含人工层(修正/问答/归组/决策/手动录入/person 编辑)零丢失**(ADR-045 journal,自 M1 起持续双写 —— M8 只验收,不补课)。另:单人导出演练 —— 导出一个孩子的 bundle,档案完整且不含他人隐私(design-debt D9)。

## 依赖关系

```
Core-0 ─> P0 人工归档/检索 ─> P1 情境 ─> P2 人工结构化 ─> P3 趋势 ─> P4 导出
                └─> 可选 AI processing plugin（建议/预填）──┘
M8 加固 —— 与 Core 并行，越早越好
```

**M1 完成即可日常使用。** 之后每一步都是在已积累的存量数据上增值 —— 这正是"归档优先"排序的意义:早一天开始存,数据资产就多一天。
