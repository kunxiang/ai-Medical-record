# AI 病历 · Personal Medical Record

一个面向个人与家庭的**长期病历归档与指标监控系统**。

拿到化验单、检查报告的第一时间拍照存档,自动识别归类;几年后凭关键词、医院、时间都能找回来。在此之上,把散落在不同医院、不同时间的检验数值汇总成可读的趋势,**作为就诊时提供给医生的佐证材料**。

## 定位

- ✅ **档案系统(DMS)优先** — 存得下、找得到、活得久
- ✅ **Core 优先、AI 可选** — 归档、手工元数据/事实、关键词检索、趋势和确定性导出不依赖模型；AI 只做可替换、可删除的建议与预填
- ✅ **多人档案** — 一个账号管理全家人,每人独立建档
- ✅ **给医生的佐证** — 输出一页纸趋势 + 可溯源原件
- ❌ **不做诊断,不做治疗建议,不替代就医**

## 三条不可动摇的原则

1. **原始影像是唯一真相来源。** AI 提取出的一切都是可再生的派生层,可版本化、可重跑。
2. **档案要活得比这个应用久。** 原件以人类可读的目录结构存放,配套 sidecar JSON;数据库只是索引,索引可以重建,原件不能。
3. **不生成医学结论。** 系统只呈现数据与来源,判断留给医生。
