# UX State Matrix · P0-P4 Core

所有状态必须保持“人工核心路径可继续”。辅助能力不可用时隐藏辅助动作，不把核心数据标红。

## 1. 导航与权限

| 区域 | owner | editor | viewer | 移动入口 |
|---|---|---|---|---|
| 档案/搜索/原件 | 读写 | 读写 | 只读 | 底栏“档案” |
| 采集 | 可用 | 可用 | 隐藏 | 全局 FAB |
| 情境 | 读写 | 读写 | 只读 | 采集 CTA、详情/数据内 |
| observation/medication/timeline event | 读写 | 读写 | 只读 | 底栏“数据” |
| 趋势 | 读写监控组 | 读写监控组 | 只读 | 底栏“趋势” |
| 导出 | 生成/下载 | 生成/下载 | 下载已授权内部导出 | 人物摘要/趋势内 |
| 公开分享 | 创建/撤销/历史 | 隐藏 | 隐藏 | 导出完成页内 |
| 智能辅助 | 配置范围内 | 使用建议 | 只读历史建议 | 账户设置/文档建议面板 |

底栏固定四项：档案、数据、趋势、账户。不得新增“情境/导出/AI”平级入口。

## 2. 全局与 capability

| 条件 | 展示 | 可继续动作 |
|---|---|---|
| capability 请求失败 | 不展示 provider 错误；标记“智能辅助状态未知” | 全部 core 动作，按 off 处理 |
| processing off | 无等待识别/失败 badge | 人工整理/录入/检索/导出 |
| plugin 过期/失败 | 仅建议面板中性提示 | 人工路径与历史建议 |
| 离线 | 顶部弱提示、逐项同步状态 | 本地采集、情境草稿、observation 草稿、浏览已缓存原件 |
| 401 | 保存本地草稿后登录 | 登录后恢复并重试同 operation |
| revision 409 | 逐字段 base/current/draft 比较 | 采用远端、保留本地后新 revision、逐字段合并 |

## 3. 采集与情境

| 条件 | 展示 | 恢复/替代 |
|---|---|---|
| 模板已缓存 | 拍摄完成后“补充 3–5 个问题，可跳过” | 立即离线作答 |
| 模板未缓存 | “当前离线，稍后补充” | 完成采集；建立 pending 占位，不阻止上传 |
| 文档未上传 | 本地文档与 session 均显示待同步 | 保留 client_document_id，联网后先文档后绑定 |
| session 未同步 | 答案本地可继续编辑 | 同 operation 重试 create/answers |
| 音频/照片待上传 | 答案显示“原件待上传” | 后台续传；可改为文字或删除附件 |
| 麦克风拒绝 | 说明浏览器权限 | 文字输入始终可见；可稍后重试录音 |
| 媒体过大/格式错 | 字段级错误 | 转码/重新选择/改文字；其他答案不丢 |
| 条件题隐藏 | 明确“不适用”且不计未完成 | 上游答案变化时确定性恢复题目和旧草稿提示 |

## 4. 文档、PDF 与人工数据

| 条件 | 展示 | 可继续动作 |
|---|---|---|
| 图片 | 点击/缩放/原图 | 元数据与数据录入 |
| PDF 浏览器支持 | 分页、缩放、页码 | 选页/来源 bbox |
| PDF 无内嵌预览 | 文件名、页数、大小与诚实提示 | 新标签打开/下载；手工录入仍可用 |
| 原件缺失 | “来源原件不可用”与 stable page id | 查看事实/审计；禁止猜测替代页 |
| 无元数据 | 空字段 + 编辑 CTA | 只要求 person；其余可空 |
| 旧 AI 建议 | “建议”徽标、逐字段 diff | 接受选中字段、人工覆盖、忽略 |
| 第 N 行无效 | 行/列内联错误与总览 | 整批不提交；修复后同 operation 保存 |
| >100 行 | 显示分批进度与总数 | 客户端按 100 分块，各块独立 operation；失败块可续 |
| 未映射 concept | “待整理”，不画趋势 | 搜索 catalog、人工映射、保留原值 |
| unit 不可换算 | 保留原单位，标“未换算” | 同单位序列可看；可人工修正 unit |

人工表格必须支持：粘贴 TSV/CSV、报告级日期/标本/方法/设备、复制上一行/整列、键盘移动、自动解析 comparator/value/unit、只录监控指标、离开保护。

## 5. 趋势

| 条件 | 展示 | 动作 |
|---|---|---|
| 0 点 | “还没有已确认数据” | 录入数据/查看待映射 inbox |
| 1 点 | 单点与该报告 reference；“尚不能形成趋势” | 打开来源 |
| 不可比 unit/series | 分线或不连线，说明维度差异 | 筛选 series/修正映射 |
| 同日无时间 | 标“仅日期”，不表示先后 | 打开来源 |
| 来源缺失 | 保留点并标 unavailable | 查看事实详情 |
| 大数据 | 标总点数与下采样版本 | 缩放分页/下载全量 |

## 6. 导出与分享

| 条件 | 展示 | 动作 |
|---|---|---|
| 无确认事实 | 缺口说明 | 返回数据录入/改范围 |
| 原件估算过大 | 字节/页数与上限 | 缩小日期、取消原件、改 person bundle |
| pending/running | 进度和可离开提示 | 后台继续，不重复创建 |
| failed | 安全错误摘要、attempt | retry 同 job；不显示 provider 术语 |
| 结果对象缺失 | “文件需重新生成” | retry 原请求 |
| 数据已变化 | “生成后数据有更新” stale badge | 预览差异并生成新版 |
| 分享创建前 | person、范围、内容、到期、公开链接风险 | owner 明确确认 |
| 分享有效 | 一次复制链接、到期、撤销、访问状态 | 撤销/新建 |
| 分享过期/撤销 | 公开页统一“链接不可用” | 不泄漏存在性 |

导出预览先展示一页纸内容和数据 gap；二维码只是同一 share URL 的可选表现，不保存新的 token。

## 7. 可用性测量

| 任务 | gate |
|---|---|
| 回访用户采集一份文档 | ≤10 秒，约 2 次应用内动作 |
| 采集 + 3 个点选 + 2 个文字/语音入口 | <90 秒，可全部跳过 |
| 10 行人工数据录入 | 桌面 ≤3 分钟；移动 ≤5 分钟；每行重复字段 ≤2 次 |
| 找到已知旧文档 | <60 秒 |
| 已有数据 preview→生成→下载摘要 | 用户操作 ≤30 秒 |
| 医生定位最新值/变化/来源 | 3–5 名医生中位数 ≤3 秒（P4 发布前真实脱敏样例） |
